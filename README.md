One word for the whole internet: **doomscroll**. The endless, compulsive scroll through bad news, hot takes, memes and strangers' arguments at 2 a.m., knowing you should stop and scrolling anyway.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the single word to `out/entry.txt`.
